# basehub-marketing — risks and open questions

| ID | Risk | State | Notes |
|---|---|---|---|
| BH-A | `baseline-v1` is not yet proven live | OPEN | Proven offline in Baseline CI: the offline bootstrap with the blueprint's own hooks, the stage lane's own steps in a staged job tree, the site served by `wrangler dev` and smoke-tested with the component's own command, unconnected and then built against a stand-in BaseHub. A console bootstrap, then a repository connected to it, closes it |
| BH-B | The connected site has not met BaseHub itself | OPEN | The connected build is proven against a stand-in that answers the SDK's own GraphQL and ref resolution from a fixture; BaseHub's real schema, a real token, the forms' events, the blog's search and the toolbar's draft mode on Workers are still to see. The first connected product closes it |
| BH-C | **Upstream carries no licence** | OPEN | basehub-ai/marketing-website-template has no LICENSE file, its `package.json` declares no `license`, and GitHub records none — so no licence grants reuse of its code, though it is published as a template for anyone to clone and deploy (Vercel's gallery, BaseHub's "Use template"). The baseline copies its code, credits it, invents no licence and copies none of its demo content (the sample is written for the baseline). The registry row is unlisted until BaseHub states terms |
| BH-D | A commit in BaseHub shows only after a redeploy | ACCEPTED | Every page is pre-rendered, as upstream; the owner redeploys by hand or with the `# orun: redeploy` stamp (README, "Connecting BaseHub"). Setting the token likewise builds nothing. The feeds and sitemap of a connected site render on request and are current |
| BH-E | The read token is inlined into the Worker's server bundle | ACCEPTED | It reads the repository's content, which the site publishes anyway; only server code names it, and the e2e tier checks no static asset carries it |
| BH-F | The Worker is 3.1 MiB gzipped: Workers Paid | ACCEPTED | basehub's code-block renderer bundles shiki with every grammar (6.5 MB raw) and theme; a code block's language is the editor's choice, so trimming them would break content. Free's limit is 3 MiB |
| BH-G | Next 16.3.8, not upstream's 16.0.9 | ACCEPTED | OpenNext 1.20.11 supports 16.3; 16.3 is the line every other baseline here builds on |
| BH-H | The sample projection implements only what the template asks | ACCEPTED | `filter` with `eq`, `notEq` and `in`, `orderBy`, `first`, `skip`. A new query using another argument is answered unfiltered by the sample, not wrongly by BaseHub; the tests parse every section type the page switch handles |
| BH-I | stack-tectonic 0.19.0, not 0.20.0 | ACCEPTED | 0.20.0's lane-shared install links each job's `node_modules` out of its tree, which Turbopack refuses |
