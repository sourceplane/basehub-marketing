# basehub-marketing — open risks

What is not yet proven or not yet decided. The full write-up of every risk,
including the accepted ones, is
`specs/epics/basehub-marketing/risks-and-open-questions.md`; this page lists only
what is still live, so it should be short.

| ID | Risk | State | What closes it |
|---|---|---|---|
| BH-A | Not proven live: repository creation, the brokered token, a real deploy and the probes | OPEN | One bootstrap from a tag against a workspace on Workers Paid |
| BH-B | The connected site has met only a stand-in BaseHub: the real schema, a real token, form events, search and the toolbar's draft mode on Workers are unseen | OPEN | The first product connected to a repository made with "Use template" |
| BH-C | Upstream carries no licence (no LICENSE file, no `package.json` licence, none on GitHub) | OPEN | BaseHub states terms for the template; until then the registry row is unlisted |

Accepted, and worth knowing before you change them: BH-D (a BaseHub commit
shows after a redeploy), BH-E (the token is in the server bundle), BH-F
(Workers Paid: the Worker is 3.1 MiB gzipped), BH-H (the sample projection
knows only the arguments the template uses).
